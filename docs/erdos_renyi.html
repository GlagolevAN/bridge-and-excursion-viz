Эрдёш—Реньи: обход, пуассоновский мост, связность

Связность случайного графа сводится к вероятности того, что обход не вымрет. Обход — это блуждание с шагами $\pm1$; при пуассонизации оно становится мостом, а его экскурсия считается точно.

$G(n,p)$ · фронт обхода · мультиномиальный мост · предел $e^{-e^{-c}}$

Граф $G(n,p)$: каждая из $\binom{n}{2}$ пар соединена независимо с вероятностью $p$. Обход в ширину от одной вершины описывается числом активных вершин $A_t$:

$$A_{t+1} = A_t - 1 + \operatorname{Bin}\!\left(n - t - A_t,\ p\right), \qquad A_0 = 1 .$$

Вершина $t$ обрабатывается на шаге $t$; каждая из ещё не открытых вершин присоединяется независимо. Граф связен тогда и только тогда, когда обход открыл все вершины, то есть $A_t > 0$ до самого конца и $A_T = 0$. Порог связности — $p_c = \log n / n$.

3.1Галерея $G(n,p)$ вокруг порога

Один и тот же генератор при трёх разных $p$: ниже порога граф распадается на мелкие компоненты, на пороге появляется гигантская компонента, выше порога граф связен. Цвет вершины — её компонента связности; жирные рёбра принадлежат гигантской компоненте.

—pc = log n / n
—доля гиганта при p = pc
—рёбер при p = pc
Раскладка вершин — пружинная (силы отталкивания и притяжения по рёбрам), начальное положение — окружность; при одном и том же зерне картинка воспроизводится. Компоненты считаются системой непересекающихся множеств.

3.2Фронт обхода и линия нулевого сноса

При $p = c/n$ средний шаг фронта равен $\mathbf{E}[A_{t+1} - A_t] = p\,(n-t) - 1 - p A_t$, поэтому линия $a = n - t - 1/p$ разделяет два режима: ниже неё фронт в среднем растёт, выше — вымирает.

$$A_{t+1} - A_t = \operatorname{Bin}\!\left(n - t - A_t,\ p\right) - 1, \qquad \mathbf{E}\Delta A_t = p\,(n - t - A_t) - 1 .$$
Серый пунктир — коридор $0 \le A_t \le n-t$; коричневая линия — нулевой снос $a = n-t-1/p$. При $c<1$ фронт быстро вымирает, при $c>1$ открывает положительную долю вершин, при $c=1$ задерживается на масштабе $n^{2/3}$.
—связных прогонов
—открыто вершин
—шагов обхода
Прогоны независимы, каждая траектория — один вызов точного биномиального генератора. «Открыто вершин» — среднее по прогонам, знаменатель — $n$.

3.3Пуассоновский мост и точная экскурсия

Пусть $X_1,\dots,X_{n-1}$ независимы и пуассоновские с $\lambda_t = q\,(1-p)^{t-1}$. При условии $\sum X_t = n-1$ их распределение — полиномиальное, поэтому мост $S_k = \sum_{t\le k}(X_t - 1)$ выбирается одним вызовом мультиномиального генератора, без сэмплирования с отвержением.

$$\lambda_t = q\,(1-p)^{t-1},\qquad q = \frac{(n-1)p}{1-(1-p)^{n-1}}, \qquad (X_1,\dots,X_{n-1}) \sim \operatorname{Mult}\!\left(n-1,\ \frac{\lambda}{\sum\lambda}\right).$$
—P(экскурсия), ДП
—Монте-Карло
—стандартная ошибка
Нижняя панель: точная вероятность экскурсии (сплошная) и оценка по выборкам пуассоновского моста (точки с интервалом $\pm2\sigma$). Обе величины — для одного и того же $C$ и разных $n$.

3.4Связность и предел $e^{-e^{-c}}$

Точная вероятность связности распадается на множитель появления гигантской компоненты и вероятность экскурсии обхода:

$$P_n(p) = \left(1-(1-p)^{n-1}\right)^{n-1}\cdot \mathbb{P}\!\left(S_k \ge 0,\ 1\le k\le n-2 \ \middle|\ S_{n-1}=0\right).$$

При $p = (\log n + c)/n$ выполнено $P_n(p)\to e^{-e^{-c}}$ при $n\to\infty$. Кривые для растущих $n$ должны ложиться на этот предел — это и есть коллапс по $c$; правая панель показывает тот же порог в координатах $(p, P_n)$.

—Pn в точке pc
—e−1
—max |ДП − предел|
Точные значения считаются динамикой по пуассоновским весам $w_t(j)=\lambda_t^j/j!$; асимптотика $e^{-e^{-c}}$ нарисована отдельной жирной линией. Пересчёт сетки занимает до пары секунд.
